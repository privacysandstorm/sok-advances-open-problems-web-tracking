# Evolution-timeline labels → tracking-mechanism / artifact mapping

Each label in `evolution-timeline.drawio` / `.pdf` (generated by
`evolution-timeline-gen.py`) mapped to the **tracking mechanism(s)** it defends
against and the **targeted artifact(s)** it acts on. Taxonomy matches the
systematization table (`tables/systematization.tex`).

**Mechanism codes.** 3PC = third-party cookies · SYNC = cookie syncing ·
1PC = first-party (script-set) cookies · SUPER = supercookies/respawning ·
CNAME = CNAME cloaking · PIXEL = tracking pixels/tags · LINK = link decoration ·
BOUNCE = bounce/navigational · SCRIPT = tracking scripts & requests ·
SERVER = server-side · BFP = browser fingerprinting · DFP = device/hardware
fingerprinting · EFP = extension fingerprinting · BEH = behavioral ·
PFP = passive fingerprinting (IP/UA) · SIDE = side-channels ·
XDEV = cross-device/cross-context · AUTH = authentication-based ·
OPT-OUT = cross-cutting opt-out signal (applies to all mechanisms).

### Notes on multi-mechanism / cross-cutting labels
- **OPT-OUT** signals (DNT, GPC) and umbrella programs (Privacy Sandbox) defend
  against many mechanisms at once; the primary artifact (an HTTP header, or a
  cross-mechanism API surface) is listed.
- **Content/script blockers** (filter lists, Shields, ETP, Tracking Prevention)
  are tagged SCRIPT+PIXEL because the same engine suppresses tracking requests,
  pixels, and the scripts that set IDs; many also block known 3p-cookie hosts.
- **Cache/network/storage partitioning** is tagged SUPER (kills respawning) and,
  where it also closes a cross-site oracle, SIDE.
