\section{Open Science}
\label{sec:open-science}

The main artifact produced by our work consists in the thematic organization and categorization of the literature on web tracking that we identified as relevant to the scope of our SoK.
%
As a result, we release the code used to automatically search for papers along with the keywords used to filter publications during our literature review, as explained in~\autoref{sec:methodology}.
%
But, perhaps more importantly, we also provide the list of publications used for the systematization in our work with our codes, annotations, and identified themes.
%
This (\textit{anonymized}) artifact is made available at \href{https://osf.io/zsy7e/overview?view_only=a346b98bf89244b5b17d842f6fb3fb13}{this URL}.
%
Upon acceptance, we intend to submit our artifact for the \textit{Available} badge of the artifact evaluation process.

Additionally, an extended and live version of this SoK exists at this URL (\textit{anonymized for submission}) to provide more detailed explanations about the different concepts covered in the concise submitted version of the SoK.
%
This longer version takes the form of an open-source software repository that contains the source files and scripts to automatically generate and publish the documents. 
%
Our objective by doing so is to be able to maintain and update on a regular basis this longer version of the SoK in order to incorporate ecosystem changes, update it with new web tracking findings, and include potential suggestions made by the community through issues or pull requests.
